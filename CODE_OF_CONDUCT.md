# Code of conduct

This project follows the [Contributor Covenant, version
2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, keep criticism about the work and
not the person, and do not harass anyone. This applies in issues, pull
requests, reviews and anywhere else the project is discussed.

## Reporting

If someone's behaviour here is a problem, tell the maintainer privately:
[@aldodelgado](https://github.com/aldodelgado) on GitHub. Reports are read by
the maintainer only and are kept confidential.

The maintainer may remove comments, commits, issues and other contributions
that break this code, and may block a contributor who keeps breaking it.
